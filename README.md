# Amity Java Assignments

Repository for Java practical assignments.

- `assignment1/` : Solutions for Assignment 1 (Exercises 1 to 10 - Introduction to Java)
- `assignment2/` : Solutions for Assignment 2 (Exercises 1 to 15 - Object Oriented Features)
- `assignment3/` : Solutions for Assignment 3 (Exercises 1 to 10 - Exception Handling and Multithreading)
- `assignment4/` : Solutions for Assignment 4 (Exercises 1 to 7 - Collections and GUI Programming)
